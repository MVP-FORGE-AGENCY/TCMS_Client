# Proficiency Check Procedures

This document outlines the procedures for conducting proficiency checks in compliance with EASA requirements, including eligibility, multi-assessor evaluation, and signature requirements.

## 1. Overview

### 1.1 Purpose

Proficiency checks verify that personnel maintain competence in their assigned duties. They are distinct from initial training and focus on demonstrating continued proficiency.

### 1.2 Frequency

- Standard interval: **24 months**
- Interval configured per proficiency profile
- Due date calculated from last successful check

## 2. Eligibility Requirements

### 2.1 Prerequisites

Before scheduling a proficiency check, trainee must have:

- Completed **initial training** for the relevant competence area
- No **expired** mandatory training blocking eligibility
- No **absence flags** requiring refresher/initial training

### 2.2 Recency Requirements

Some proficiency profiles may require:

- Minimum recent experience (e.g., hours, tasks performed)
- Completion of preparatory briefing
- Current medical or security clearances

## 3. Assessment Process

### 3.1 Check Types

| Type               | Description                                      |
| ------------------ | ------------------------------------------------ |
| **Standard**       | Single assessor conducts full evaluation         |
| **Multi-Assessor** | Multiple assessors required per regulations      |
| **Combined**       | Proficiency check combined with training session |

### 3.2 Multi-Assessor Requirements

When required:

- Each assessor evaluates **independently**
- No discussion of individual results until both submitted
- System enforces independent evaluation submission
- Final result determined by consensus or defined criteria

### 3.3 Assessor Independence

Assessors must confirm:

- [ ] No reporting relationship with trainee
- [ ] No personal relationship affecting objectivity
- [ ] Not involved in trainee's recent training
- [ ] No conflict of interest

> **Conflict Declaration**: Assessors must declare conflicts. System will prevent assignment if conflict exists.

## 4. Scheduling

### 4.1 Planning Timeline

- Checks should be scheduled **30 days** before expiry
- System generates automatic notifications at 90, 60, 30 days
- Training Manager responsible for scheduling

### 4.2 Required Information

When scheduling a check:

- Trainee identification
- Proficiency profile
- Assessor(s) assignment
- Date and location
- Resources/equipment required

## 5. Conducting the Check

### 5.1 Pre-Check Briefing

Assessor(s) must:

- Verify trainee identity
- Confirm trainee understands the process
- Explain assessment criteria
- Address any trainee questions

### 5.2 Evaluation

- Assessor observes/tests according to profile criteria
- Scores recorded for each evaluated area
- Notes documented for any issues observed
- All criteria must be evaluated

### 5.3 Post-Check Debrief

After evaluation:

- Immediate verbal feedback to trainee
- Areas of strength highlighted
- Areas for improvement discussed
- Formal result communicated

## 6. Recording Results

### 6.1 Required Fields

For each proficiency check:

- Trainee and assessor identification
- Date and location
- Evaluation scores per criteria
- Overall result (Pass/Fail)
- Assessor comments
- Electronic signature

### 6.2 Multi-Assessor Recording

Each assessor submits:

- Individual evaluation scores
- Independent recommendation (Pass/Fail)
- Personal electronic signature

System then:

- Compares independent evaluations
- Calculates consensus result
- Flags discrepancies for review

## 7. Electronic Signature

### 7.1 Requirements

Electronic signatures must:

- Be uniquely linked to the assessor
- Include timestamp
- Be tamper-evident (locked after signing)
- Meet regulatory acceptance criteria

### 7.2 Signature Process

1. Assessor reviews recorded evaluation
2. Confirms accuracy of all entries
3. Submits electronic signature
4. System locks the record

### 7.3 Multi-Assessor Signatures

- All assessors must sign independently
- Check not finalized until all signatures received
- Timeout alerts if signature pending > 48 hours

## 8. Result Validity

### 8.1 Successful Check

Upon pass:

- New validity period begins
- New expiry date = check date + interval months
- Competence status updated to **Valid**

### 8.2 Failed Check

Upon fail:

- Retake process applies (see retake-process.md)
- Competence status updated to **Expired** or **Action Required**
- Training Manager notified

## 9. Documentation & Audit Trail

### 9.1 Record Contents

Complete proficiency check record includes:

- Pre-check confirmation
- Evaluation criteria and scores
- Assessor observations/notes
- Result determination
- Signatures with timestamps
- Any discrepancies or exceptions

### 9.2 Retention

Records retained for minimum **5 years** as per regulatory requirements.
